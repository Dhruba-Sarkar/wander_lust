# 🌍 Wanderlust: Full-Stack Accommodation Platform

A full-stack web application replicating core Airbnb functionalities, designed to handle dynamic property listings and seamless user interactions.

## 🚀 Tech Stack
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Language:** JavaScript
* **Architecture:** RESTful APIs

## ✨ Key Features
* **Dynamic Listings:** Users can view and explore diverse property details.
* **Full CRUD Operations:** Robust backend architecture allowing for the creation, reading, updating, and deletion of accommodation listings.
* **Data Management:** Efficient database schemas designed to manage dynamic booking statuses.
